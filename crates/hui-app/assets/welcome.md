# 留一点空间，给思考。

欢迎来到 **HUI**，一个安静、轻盈的 Markdown 工作空间。

把注意力交给内容。打开一份文档，或从一个新的想法开始。

> 好的工具，应当让你忘记工具本身。

## 阅读，自有节奏

在右上角切换 **阅读** 与 **源码**，或用 **分栏** 同时查看两者。选择暖白、石墨、暖纸主题，调整字号与版心，让每一页都合心意。

## 从简单的文字开始

- 用 `#` 写下标题，用列表梳理想法
- 用 **粗体** 强调重点，用 *斜体* 留下旁注
- 打开本地 `.md` 文件，修改会在停笔后自动保存
- 所有文档都留在你的设备上

### 小小的清单

- [x] 找到一个专注的阅读空间
- [x] 试试适合自己的主题
- [ ] 写下今天的第一个想法

| 写作方式 | 用途 |

| 代码块 | 保存可以重现的思路 |
| 数学公式 | 精确地描述关系 |

```rust
    let idea = "让文字回到中心";
    println!("{}", idea);
}
```
