# Пространство для мысли.

Добро пожаловать в **HUI** — спокойное и лёгкое пространство для Markdown.

## Читайте в своём ритме

Переключайтесь между исходником, разделённым видом, правкой на месте и чтением. В настройках оформления доступны тема, язык, размеры шрифта, высота строки, интервалы и ширина текста.

## Начните с простого текста

Используйте `#` для заголовков, **полужирный**, *курсив* и списки для организации мыслей.

Откройте локальный файл `.md`. Изменения сохраняются автоматически после паузы во вводе. Документы остаются на вашем устройстве.
