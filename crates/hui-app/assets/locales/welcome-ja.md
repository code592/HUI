# 考えるための余白を。

**HUI** へようこそ。静かで軽やかな Markdown ワークスペースです。

## 自分のペースで読む

ソース・分割・ライブ・閲覧を切り替えられます。文字組み設定でテーマ、言語、文字サイズ、行の高さ、段落間隔、本文の幅を調整できます。

## シンプルな文章から

`#` で見出しを作り、**太字**、*斜体*、リストで考えを整理しましょう。

ローカルの `.md` ファイルを開きましょう。入力が止まると自動保存されます。文書は端末内に保存されます。

- [x] 好みのテーマを選ぶ
- [ ] 今日最初のアイデアを書く
