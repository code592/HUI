# 实施与验收状态

更新：2026-09-08（0.2.0）。此文件区分实现、验证和计划；未列为通过的指标均不能视作达标。

## 已落地的开发预览

- 九种界面语言、默认系统语言、持久化语言选择、九语言欢迎文档与 README；UTF-8 多语种原文及字体回退。
- 三个 Rust crate 与锁定的 Slint / Blitz / 原生渲染依赖，无网页运行环境。
- 自定义 Slint 设计变量、线性 SVG 图标、三主题、阅读宽度与字号、文件栏调整、标签、大纲、查找替换、命令/导出面板、窄窗口基础布局、系统菜单。
- Rope 文档共享快照、版本校验事务、撤销重做、Unicode 字符偏移、原文不经 HTML 回写。
- 有界初始源码窗口（8192 字符）、分段定位、普通原生文本输入；实验性块命中与段落内编辑。
- 全文搜索与正则替换在后台计算；结果带文档 ID 和修订号校验。
- 本地打开、最近文件、文件夹列表、保存/另存为、停笔自动保存、未命名恢复记录、只读/外部冲突拒绝覆盖。
- Markdown/GFM、代码高亮、基础数学 SVG、merman 图表 SVG、静态 HTML/CSS 原生排版；排版工作线程及修订校验、取消检查、公式/图表结果缓存限额。
- HTML 导出；PDF 直接使用排版绘制指令，保留正文文本和矢量图形，普通语义块间分页。
- macOS ARM64 DMG、Windows x64/ARM64 便携 ZIP、Linux x64/ARM64 tar.gz；统一图标、桌面描述与 CI。Windows NSIS 脚本仍未完成安装验收。

## 已验证的边界

- 当前 macOS ARM64 原生编译与窗口检查；Windows 11 ARM 虚拟机中 ARM64 与 x64 系统仿真运行；Ubuntu 22.04 构建、Ubuntu 24.04 容器的原生渲染及 Xvfb 窗口检查。这些结果不能外推到 Windows LTSC、macOS 12/Intel 或所有实机。
- 核心单元测试覆盖 Unicode/CRLF/BOM 保存、跨窗口撤销、无效/过期事务、超长行窗口、外部冲突保留及正则替换。
- 渲染测试覆盖 GFM 基本内容、数学输出、脚本与事件属性清理。单份兼容 fixture 的视觉检查不等于 CommonMark/GFM、KaTeX 或 Mermaid 官方兼容认证。
- 实际窗口通过辅助功能文本设置输入中文、emoji 并保存；**中文 IME 候选、组合输入和软键盘未通过端到端验证**。
- 内存内核 Release 微基准：约 1 / 10 / 50 MiB 文本构建 Rope 分别约 0.479 / 7.594 / 24.876 ms；200 次有界窗口编辑 P95 约 0.060 / 0.041 / 0.025 ms。仅供本机核心回归参考，不包含磁盘打开、UI、HTML DOM、图片、公式或滚动，不代表整体性能达标。

## 未完成：阶段 1 关键风险

1. **真正的连续虚拟编辑视口**：当前按段载入原生 TextInput；大粘贴后窗口仍可增长。跨窗口鼠标选择、多光标、完整光标几何映射、输入法及无障碍平台适配未实现。
2. **50 MB 完整阅读首屏**：当前后台解析并布局全文 DOM，只绘制视口；复杂 HTML 依赖分析、块级布局虚拟化、图片延迟解码和完整图像缓存预算未实现。没有达到 50 MB 首屏 3 秒的验证证据。
3. **完整即时渲染编辑**：当前实现文档流内的无边框单块源码编辑，随输入高度重排后续内容；跨块选择、表格单元格就地编辑尚未实现。过大块会定位源码并明确提示，不能算作即时兼容完成。
4. **严格兼容对照**：尚未生成固定字体/参考浏览器版本的 KaTeX、Mermaid 官方图像与布局比较，也未补齐 Blitz CSS 差异。公式的 MathJax 显示替代属于临时实现偏离，仍需验证或替换。
5. **性能与省电**：未测整机冷启动、输入/滚动 P95、静止 CPU、内存长时稳定性、移动能耗。生产逻辑没有周期重绘定时器；这不能替代能耗测试。

## 未完成：阶段 2 桌面

- 阅读区域当前显示原生引擎输出的纹理；已接入跨段文字选择与复制；链接点击和阅读屏幕阅读器语义桥接仍未接入。
- 文件读取仍在 UI 线程；外部修改仅在保存时检测，没有文件监视器与自动重新载入。文件夹导航不是完整可展开树。
- 已增加本地图片插入和剪贴板位图粘贴（先保存文档，资源保存在 assets）；完整格式命令、查找结果前后导航、读屏与键盘全操作仍需补齐。
- 阅读位置仅保留源码段位置；像素阅读位置与字号变化后的语义锚点恢复未完成。
- PDF 超长块仍可能切行，没有脚注分页、完整链接注释、目录和打印 CSS 验收。数学是路径，不是可选公式文本。实测 PDF 提取部分汉字成为康熙部首码位、部分俄语字母出现同形字符替换；PDF 复制的逐字符保真未通过。
- HTML 导出的相对资源没有全部内嵌，复杂内联 HTML/CSS 的保真度未验收；远程资源在原生阅读中禁用。
- macOS Finder 打开事件已接入；Windows/Linux 描述与图标已打包，但完整安装/卸载、默认程序选择及多实例转发回归未完成。不会强制改变系统默认应用。
- Windows 10 LTSC 2021 / 22H2、macOS 12 Intel/ARM 与所有目标真机尚未完整验收；Windows 11 ARM 和 Linux 容器检查不等于全部平台完成。
- Linux 正式安装包、Windows 安装实测、开发者签名/公证未完成。
- 磁盘写满、突然断电、多进程并发、权限撤销、网络盘、离线安装与大批文件打开尚未完成故障注入测试。

## 未完成：阶段 3 移动

Android 和 iOS 没有可交付应用。尚未接入移动入口、文档 URI、系统分享/打开、安全区域、软键盘、触控选择、后台恢复、动态字号或真机能耗测试。窄桌面窗口截图不能当作移动端实现。
