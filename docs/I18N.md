# Language support (0.2.0)

The UI supports `zh-Hans`, `zh-Hant`, `en`, `ja`, `ko`, `fr`, `de`, `ru`, and `es`. A new profile follows the operating system. Unsupported system languages fall back to English. `zh-TW`, `zh-HK`, `zh-MO`, and `zh-Hant` use traditional Chinese; explicit `zh-Hans` takes precedence over a traditional region. Regional variants such as `fr-CA`, `es-MX`, and `en-GB` use their supported base language.

Use **Typography → Language** to choose a language or return to the system setting. Preferences persist as a language tag, not a translated label. System language is queried at application startup through `sys-locale`. Native OS dialog buttons remain controlled by the OS. Third-party diagnostic details may use the language supplied by their underlying library.

## Implementation

- `crates/hui-app/assets/locales/*.json`: 138 shared UI and application diagnostic keys per language.
- `crates/hui-app/src/i18n.rs`: bundled catalog loading, locale resolution, named placeholder formatting, and reactive Slint global binding. Catalogs initialize once; no polling, network requests, or per-frame reloads.
- `welcome-*.md`: localized example documents, created only when a new application session needs a welcome document. Language changes never rewrite an opened document.
- `Preferences.language`: empty or `system` means system default; older preferences migrate without resetting typography.
- The native renderer accepts a diagnostic translator. Only generated labels are translated; Markdown and code are never passed through translation lookup. Layout cache keys include the UI locale.
- The sidebar stores a boolean for recent-file mode; it does not compare translated labels to control behavior.
- Text is UTF-8 in the Rope model, with native system font fallback. Linux packages document `fonts-noto-cjk`; fonts are not silently downloaded.

## Reproduce checks

```sh
python3 scripts/check-locales.py
cargo test --workspace --locked
cargo clippy --workspace --all-targets --locked -- -D warnings
```

The locale check verifies key parity, non-empty translations and exact named-placeholder parity. Core integration tests edit, undo, redo and save all nine languages, combining accents and emoji while preserving CRLF and Unicode filenames. Preference tests cover all nine choices and returning to the system default.

For deterministic GUI review, use a separate temporary `HUI_DATA_DIR` and set `HUI_LANGUAGE=de`, for example:

```sh
HUI_DATA_DIR=/tmp/hui-language-qa HUI_LANGUAGE=de cargo run -p hui-app -- --screenshot /tmp/hui-de.png settings
```

`HUI_LANGUAGE` controls the system-default branch for QA; an explicit saved selection takes precedence. Add `compact` to test a narrow window. `packaging/smoke/multilingual.md` covers all scripts in headings, tables, prose, emphasis and code. Package smoke scripts use this fixture for PNG/PDF export as well as GUI startup.

A screenshot or text insertion test does not certify Japanese/Korean/Chinese IME composition behavior on every OS. Dedicated IME, accessibility and mobile acceptance remain open, as listed in STATUS.md.
